# 🚀 YouTube Auto-Publisher & Manager (Facts Channel)

This repository contains a fully automated, headless Python script running on GitHub Actions. It acts as an "Auto-Manager" for a YouTube Facts Channel. 

You simply upload a raw video as **Private** or **Unlisted**, and this bot will automatically detect it, apply a random title, description, and tags from your text files, make it **Public**, and send a success alert to Telegram.

## ✨ Features
* **🤖 Headless Operation:** Runs 100% in the cloud via GitHub Actions.
* **🧠 Stateful Cooldown System:** Remembers which Titles, Descriptions, and Tags were used and puts them on a 30-day cooldown so your content never looks repetitive.
* **📝 File-Based CMS:** Easily update `title.txt`, `description.txt`, `hashtag.txt`, and `tag.txt` without touching the code.
* **🚨 AI Fallback:** If you run out of titles, it automatically uses Pollinations AI to generate a highly engaging title.
* **📱 Telegram Alerts:** Sends an instant notification when a video goes live.

---

## 📁 Repository Structure

* `main.py` - The core automation script.
* `.github/workflows/main.yml` - The GitHub Action timer that runs the script every hour.
* `history.json` - The bot's memory (keeps track of the 30-day cooldowns).
* `title.txt`, `description.txt`, `hashtag.txt`, `tag.txt` - Your custom content files.
* `requirements.txt` - Python dependencies.

## ⚙️ Setup & Installation

### Step 1: Enable YouTube API v3
1. Go to the [Google Cloud Console](https://console.cloud.google.com/).
2. Create a Project and enable the **YouTube Data API v3**.
3. Create OAuth 2.0 Credentials (Desktop App) to get your Client ID and Client Secret.

### Step 2: Configure GitHub Secrets (Crucial)
This bot requires 5 environment variables to securely connect to YouTube and Telegram. 
Go to **Settings > Secrets and variables > Actions > New repository secret** and add the following keys exactly as written below:

| Secret Name | Example Value | Where to find it |
|---|---|---|
| `YOUTUBE_CLIENT_ID` | `123456-abc.apps.googleusercontent.com` | Google Cloud Console > Credentials |
| `YOUTUBE_CLIENT_SECRET` | `GOCSPX-abc123xyz456` | Google Cloud Console (Under Client ID) |
| `YOUTUBE_REFRESH_TOKEN` | `1//0eXyZ...` | Generated by authenticating your Google Account via Python locally for the first time. |
| `TELEGRAM_TOKEN` | `1234567890:AAH_xyz123_abc` | Telegram: Create a bot using [@BotFather](https://t.me/BotFather). |
| `TELEGRAM_CHAT_ID` | `-1001234567890` (Group) or `987654321` (Private) | Use a bot like @RawDataBot to find your Chat ID. |

### Step 3: Grant GitHub Actions Write Permission
Because this bot updates `history.json` to remember cooldowns, GitHub needs permission to push code back to the repository.
1. Go to repository **Settings > Actions > General**.
2. Scroll down to **Workflow permissions**.
3. Select **Read and write permissions**.
4. Click **Save**.

## 🚀 How to Use (Daily Workflow)

Once everything is set up, your daily workflow becomes incredibly simple:
1. Open the YouTube App or YouTube Studio.
2. Upload your short/video and set the visibility to **Private** or **Unlisted**.
3. **Do nothing else.** 

Within the next hour, the GitHub Action will wake up, apply the perfect SEO metadata from your text files, publish the video, and ping your Telegram!
